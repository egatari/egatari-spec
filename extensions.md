# Etoki extension registry

Extensions carry platform-specific information without changing Etoki (spec §9A). Register a name by adding a row (pull request). Names are first-come; the definition document must state the extension's `v` versions and the shape of its data.

| Name | Owner | Purpose | Definition |
|---|---|---|---|
| `canon` | Kumoi Lab (rs-interactive-lecture) | questions/hints per step, core questions, chapter grouping for the canon interactive-lecture app | to be written in the canon repository |
